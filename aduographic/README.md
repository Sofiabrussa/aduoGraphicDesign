# 🎨 Aduo Graphic Design  

**Aduo Graphic Design** es un proyecto orientado al diseño gráfico digital, donde se combinan creatividad y tecnología para crear piezas visuales modernas, minimalistas y funcionales.  
Este repositorio reúne los recursos, prácticas y desarrollos realizados en el marco de mi formación en **Ingeniería en Sistemas** y mis intereses en **frontend y diseño digital**.  

---

## 🚀 Características principales  
- Diseño visual con enfoque en **estética minimalista y profesional**.  
- Implementación con **React.js** para la interfaz.  
- Uso de **JavaScript** y **CSS** para la lógica y el estilo.  
- Versionado y colaboración mediante **GitHub**. 
- Deploy con Render

---

## 🛠️ Tecnologías utilizadas  
- **React.js**  
- **JavaScript (ES6+)**  
- **HTML5 & CSS3**  
- **Git / GitHub**

## 🔧 Instalación y uso  
1. Clonar el repositorio:  
   ```bash
   git clone https://github.com/Sofiabrussa/aduoGraphicDesign.git

2. Instalar dependencias: npm install
3. Iniciar el proyecto: npm start
4. Abrir en el navegador: http://localhost:3000
